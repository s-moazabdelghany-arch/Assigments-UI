Campus Events Guide — Assignment 1

Files:
- index.html: home page
- events.html: event catalogue
- event-details.html: featured event and review form
- schedule.html: timetable
- registration.html: registration form
- style.css: shared styling
- assets/images/: local SVG posters and illustrations
- assets/media/: reserved for local media if you later add your own file

How to open:
1. Extract this folder.
2. Open index.html in Chrome or Edge.
3. Use the navigation to visit all five pages.
4. Test at mobile, tablet, and desktop widths using browser developer tools.

Important:
- Event names, dates, venues, and contact details are sample content for the assignment.
- The forms demonstrate HTML5 validation only; they do not send or store submissions.
- The video sample needs an internet connection.
- The dark mode control uses CSS :has() and a checkbox, without JavaScript.
- Replace campus_events_moaz with the folder name your instructor requests if needed.
- Review the code and make sure you can explain it during the individual discussion.
